# Historical documentation archive

> [!CAUTION]
> Everything in this directory is a historical snapshot. It records designs,
> implementation reports, and verification claims from earlier versions of the
> project. It is not evidence of the current API, model compatibility, test
> status, performance, or production readiness.

The files are retained because they explain how earlier decisions were made and
may be useful when comparing the revival with the pre-revival codebase. They
have deliberately not been rewritten to match the current implementation.

For maintained documentation, start with:

- [the repository README](../../README.md) for current scope and safety limits;
- [the documentation index](../README.md) for maintained guides;
- [the model catalog](../models/supported_models.md) for support-tier semantics;
- [the registry architecture](../architecture/model_registry.md) for generated
  metadata; and
- [the time-series legacy note](../legacy/TIMESERIES.md) for the quarantined
  Chronos path.

Historical reports are excluded from the published crate package. Paths,
commands, benchmark numbers, model lists, completion checkboxes, and phrases
such as “production ready” within these files describe only the snapshot in
which they were written.
